# MCP Integration

Experiments connecting Claude AI to external tools and services via the Model Context Protocol (MCP).

## What is MCP?

Model Context Protocol (MCP) is an open standard by Anthropic that lets LLMs connect to external tools, databases, and APIs in a structured way.

## Integrations Explored

- File system access via MCP tools
- Custom tool definitions and schemas
- Multi-step agentic workflows

## Setup

```bash
npm install
npm run start
```

## Tech

Node.js · Anthropic SDK · MCP · TypeScript
